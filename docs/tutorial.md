## アクションを有効にする

ポップアップを開き，「HTTP Actionsを有効にする」のトグルをオンにします．オフにすると，登録済みアクションは右クリックメニューから非表示になります．

## アクションを作成する

1. 「作成・編集」タブを開く
2. アクション名，HTTPメソッド，送信先URLを入力する
3. 右クリックメニューに表示するコンテキストを選択する
   - `Page`: ページ上で右クリックしたとき
   - `Selection`: 文字列を選択して右クリックしたとき
   - `Link`: リンク上で右クリックしたとき
   - `Image`: 画像上で右クリックしたとき
4. 必要に応じてヘッダー，本文，タイムアウト，実行時入力を設定する
5. 「保存」をクリックする

### JSON（KV）形式

項目を追加してキーと値を入力します．`true`，`false`，数値，オブジェクト，配列はJSONの値として扱われます．

次のように設定すると，選択文字列とページURLをJSONとして送信できます．

```json
{
  "text": "{{selection}}",
  "source": "{{page.url}}"
}
```

### Raw形式

Rawモードでは，JSONやプレーンテキストをそのまま入力できます．Raw JSONでページ情報を文字列として使う場合は，プレースホルダーをJSON文字列の引用符内に配置してください．

### 実行時入力

アクション編集画面の「実行時入力」で，実行時に入力する項目を定義できます．入力項目のキーは，URL，ヘッダー，本文で`{{userId}}`のように参照します．

実行時入力を定義したアクションは，実行前に入力画面を表示します．入力値は実行ごとに入力し，保存されません．入力種別はテキストまたはパスワードから選択でき，必須項目が未入力の場合は実行できません．

## アクションを実行する

- 「一覧」タブの再生ボタンをクリックする
- ページ上で右クリックし，「HTTP Actions」からアクションを選択する

実行結果はChromeの通知とポップアップに表示されます．ポップアップでは，最後に実行したアクションのHTTPステータス，レスポンス本文，レスポンスヘッダーを確認できます．実行履歴やエラーはポップアップ下部のログパネルに表示されます．

## 変数とシークレットを使う

「変数」タブで登録した値は，アクション内から次の形式で参照できます．

```text
{{var.apiBase}}
{{secret.token}}
```

シークレットの値は画面上でマスクされますが，暗号化保存ではありません．信頼できないPCでは登録しないでください．

## 利用できるプレースホルダー

- `{{page.url}}`: 現在のページURL
- `{{page.title}}`: ページタイトル
- `{{page.domain}}`: ページのドメイン
- `{{selection}}`: 選択文字列
- `{{link.url}}`: 対象リンクのURL
- `{{image.url}}`: 対象画像のURL
- `{{var.キー名}}`: ユーザー定義変数
- `{{secret.キー名}}`: シークレット

変数とシークレットのキーには，英数字，日本語などの文字，`_`，`-`，`.`を使用できます。空白やその他の記号は使用できません．

## ログを確認する

ポップアップ下部の「ログ」パネルで実行結果やエラーを確認できます．「クリア」ボタンでログを削除できます．シークレットをURLに埋め込んだ場合，ログには展開前のアクションURLが記録されます．

## 困ったときは

- 選択文字列が空の場合は，通常の`http://`または`https://`ページで試してください
- メニューに表示されない場合は，拡張機能とアクションが有効か確認してください
- JSONエラーの場合は，引用符，カンマ，プレースホルダーの位置を確認してください
